# TO-DO-LIST
A simple to-do list. This is my basis python project.
## Project Description
The To-Do List is a simple task management application that helps users organize their daily activities. Users can add, manage, complete, and delete tasks easily.

## Features
- Add New Tasks
- View All Tasks
- Mark Tasks as Completed
- Delete Tasks
- Simple and User-Friendly Interface
- Manage Daily Activities

## Technologies Used
python

## How to Use
1. Open the To-Do List application.
2. Enter a task.
3. Click the Add button.
4. Mark tasks as completed when finished.
5. Delete tasks when they are no longer needed.

## Project Purpose
The purpose of this project is to make daily task management easier and improve productivity.
